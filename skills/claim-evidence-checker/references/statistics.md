# Statistical Claim Reference

Use when the manuscript uses inferential or significance language.

## Key distinctions

Do not conflate:
- numerical difference
- practical importance
- statistical significance

“Significant” can be ambiguous.

If no statistical test is reported, prefer:
- higher
- lower
- larger
- smaller
- notable
- substantial

only when supported by effect magnitude/context.

## Check
- sample size
- independence of replicates
- uncertainty
- confidence intervals
- test choice
- multiple comparisons
- effect size
- p-value interpretation

Do not invent a statistical requirement if the study design does not call for inferential statistics.
