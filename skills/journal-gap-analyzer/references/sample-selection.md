# Benchmark Sample Selection

Use this reference before building a Journal Benchmark.

## Preferred benchmark sample

Prioritise papers that match:

1. target journal;
2. article type;
3. recent publication period;
4. broad research domain;
5. methodology;
6. contribution scale.

A journal publishes heterogeneous work. The goal is to create a **comparable local benchmark**, not a universal journal stereotype.

## Sample size

Preferred: 5–10 papers.

Exploratory minimum: 3 papers.

When using only 3 papers:
- lower Benchmark Confidence;
- avoid narrow style conclusions;
- report high within-sample uncertainty when present.

## Recency

Prefer recent papers when the goal is current journal alignment.

Older landmark papers may be informative for scientific context, but should not dominate a current style/structure benchmark.

## Full text vs abstract only

Full text is strongly preferred for:
- Methods reporting;
- Results depth;
- Discussion depth;
- literature positioning;
- limitations;
- figure/table patterns.

Abstract-only evidence should not be used to score these dimensions with high confidence.

## Outlier handling

If one paper is unusually short, unusually long, highly theoretical, highly applied, or structurally atypical:
- mark it as an outlier candidate;
- do not treat its pattern as a journal norm;
- compare against the central tendency of the sample.

## Article-type mismatch

Do not mix these without adjustment:
- original research;
- reviews;
- perspectives;
- methods papers;
- short communications;
- editorials.

If mixed samples are unavoidable, score only dimensions that remain comparable.

## User-selected papers

If the user provides papers they consider representative, use them, but still report whether they are actually comparable to the manuscript.

Do not silently discard user-supplied benchmark papers; explain exclusions or reduced weighting.
