# Particle / DPM Physics Sanity Reference

Use only for particle transport / deposition studies.

## Candidate mechanisms
- inertia
- impaction
- gravitational settling
- turbulent dispersion
- recirculation residence time
- near-wall transport
- interception
- rebound
- trapping / sticking
- shielding
- geometry-induced acceleration

## Avoid simplistic rules
Do not assume:
- larger particles always deposit more
- smaller particles always remain suspended
- gravity always dominates
- recirculation always increases deposition

## Useful diagnostics
- Stokes number
- particle trajectories
- residence-time distribution
- force-magnitude comparison
- deposition efficiency by size
- velocity field near deposition hotspot
- particle-wall fate statistics
- sensitivity to wall-interaction settings
